Architecture

6-stage sequential diagnostic chain. Paste the ENTIRE prompt into any AI, feed it messy client data, and it produces a scored, evidenced, prescriptive commercial diagnostic with a Kill/Fix/Accelerate verdict. Stages: 00-A INTAKE (20-scenario router + Bellingcat triangulation) → 00-B TAXONOMY SCAN (30-problem detection including 2.11 Procurement Black Box) → 00-C EVIDENCE AUDIT (source verification, Bellingcat grading) → 00-D PRESCRIPTION (intelligent source gap analysis + 00-D Proof Check vs G-22) → 00-E DASHBOARD GENERATOR (visual-ready data output) → 00-F VERDICT (Kill/Fix/Accelerate with Corridor Test). Human gate between each stage. v5: Platform Adapters on all 6 stages, SCQA structure, Tufte tables, MECE taxonomy, Bellingcat triangulation on intake.

Engine Logic

Sequential pipeline: output of each stage feeds the next. 00-A eats the mess (any data format) and either processes a data dump or matches to 1 of 20 scenarios across 7 categories (Prospecting, First Meeting, Active Pursuit, Renewal/Protect, Expansion, Portfolio/Leadership, Rescue) — each scenario prescribes the exact prompt chain. 00-B scans against 30-problem taxonomy. 00-C verifies evidence. 00-D prescribes actions + identifies data gaps. 00-E generates dashboard data. 00-F delivers the verdict. Human reviews between each stage before proceeding.

Power of "NONE"

Feed it anything — messy CRM exports, corridor gossip, LinkedIn scrapes, photos, partial data. The engine structures whatever it receives. More data = higher confidence. Less data = lower confidence with explicit gap flags. Minimum input: a company name and a scenario description.
