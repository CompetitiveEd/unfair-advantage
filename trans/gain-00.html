THE DIAGNOSTIC ENGINE v5 — Commercial Diagnostic Chain

DIAGNOSTIC ENGINE
Architecture

6-prompt sequential chain that turns messy client data into a scored, evidenced, prescriptive commercial diagnostic with a Kill/Fix/Accelerate verdict. Model-agnostic (Claude, ChatGPT, Gemini, Deepseek). Human gate between each step. 30-problem taxonomy across 4 levels. v5: Scenario Router (20 scenarios), Bellingcat source triangulation, Intelligent Source Gap Analysis, SCQA verdict.

The Chain (run in sequence)
00-A INTAKE — "Eat the mess" 00-B TAXONOMY SCAN — Score against 30 problems 00-C EVIDENCE AUDIT — "What's real?" 00-D PRESCRIPTION — Prompt chain + source gap analysis 00-E DASHBOARD — Visual output generation 00-F VERDICT — Kill / Fix / Accelerate
00-A Scenario Router (20 scenarios)

Before processing data, 00-A pattern-matches the situation to one of 20 scenarios across 7 categories and prescribes the exact prompt chain, sources needed, and first question to ask:

PROSPECTING: Break into company / Reach a person / Hiring signals FIRST MEETING: New client / Known company ACTIVE PURSUIT: RFP bid / Competing against / Deal gone quiet RENEWAL: Renewal coming / New leader / Competitor circling EXPANSION: Grow account / New department PORTFOLIO: Triage pipeline / Team underperforming / Post-acquisition RESCUE: Deal dying / Losing account
30-Problem Taxonomy (4 Levels)

Level 1 — Company/Portfolio (7): 1.1 Margin Compression, 1.2 M&A Value Leakage, 1.3 Hero-Dependency, 1.4 ICP Drift, 1.5 Measurement Trap, 1.6 Vendor Incentive Addiction, 1.7 Proposition-Reality Gap

Level 2 — Deal/Pursuit (11): 2.1 Happy Ears, 2.2 Pipeline Inflation, 2.3 No-Decision Epidemic, 2.4 Stakeholder Blindness, 2.5 Discovery Failure, 2.6 Cycle Drag, 2.7 Competitive Displacement Blindness, 2.8 Phantom Champion, 2.9 Dead Deal Denial, 2.10 Loss Review Theatre, 2.11 Procurement Black Box

Level 3 — People/Behavioural (8): 3.1 Licence Deficit, 3.2 Capability-Application Gap, 3.3 Accountability Vacuum, 3.4 Hiring Pattern Failure, 3.5 Manager Capability Gap, 3.6 Motivation Architecture Failure, 3.7 Pressure Spiral, 3.8 Fear-Driven Selling

Level 4 — CRM Signals (4): 4.1 Email Activity, 4.2 Meeting/Calendar, 4.3 LinkedIn/Connection, 4.4 CRM Audit Trail

Accepted Inputs (00-A)

CRM exports, pipeline reports, meeting notes, call transcripts, pitch decks, LinkedIn profiles, org charts, company websites, annual reports, email threads, handwritten notes (photographed), verbal descriptions, previous diagnostic outputs, service desk data, financial data (P&L, margin reports, comp plans), conversation intelligence exports. Any format. Any combination. Messy is fine.

Key Features

Bellingcat Triangulation (00-A): Every claim tagged TRIANGULATED (2+ independent sources) or SINGLE-SOURCE. Feeds evidence quality into 00-C.

MECE Classification (00-B): Every problem coded. No overlaps. No gaps. Severity rated 1-3.

Evidence Grading (00-C): VERIFIED (hard data), CLAIMED (stated, unverified), INFERRED (deduced from patterns), MISSING (gap identified).

Intelligent Source Gap Analysis (00-D): Cross-references intake data against what each prescribed prompt needs. Shows exactly what's PROVIDED vs MISSING with where to get it. Prompt-by-prompt input requirements table.

Corridor Test (00-F): The entire diagnostic compressed to one sentence under 15 words. If you can't say it in the corridor, the diagnostic isn't done.

Frameworks
Bellingcat (source triangulation) MECE SCQA (Minto) Tufte (data-ink ratio) Gawande (forensic checklist) One-Page Rule (Corridor Test)
GAIN Drivers
Safety (primary — expose hidden risk) Order (structure the chaos) Power (predictive advantage)
Feeds From

Any data. Any format. Any quality. Scenario description with no data also accepted (Mode B). G-22 output is premium intake.

Chains Into

00-D prescribes the exact GAIN prompt chain to run. Feeds into any G/A/I/N/P prompt as prescribed. 00-E generates dashboard JSON. Portfolio mode feeds gain-portfolio-triage.html.

Verdict Outcomes
KILL — Walk away. The evidence says this is not winnable/fixable. FIX — Structural problems. Addressable with specific interventions. ACCELERATE — Fundamentals are sound. Remove friction and scale.
