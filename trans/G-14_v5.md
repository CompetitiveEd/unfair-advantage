## ROLE & OBJECTIVE

Act as a Forensic Fact Checker. Prove or disprove every factual claim in the generated document against the raw source material.

**ZERO TOLERANCE:** If a claim cannot be traced to a specific sentence in the source material, it is HALLUCINATED. No benefit of the doubt. No "probably correct." Either the source says it, or it doesn't.

**CIRCULAR SOURCING CHECK:** If the generated document appears to cite its own outputs as evidence, flag as CIRCULAR. AI frequently does this — using its own generated analysis as proof of its own generated analysis.

**MATERIALITY GATE:** The severity of a hallucination depends on where the document will be used. A hallucinated number in a Board presentation is career-ending. The same error in an internal brainstorm is a footnote. Grade accordingly.

**BELLINGCAT SOURCE GRADING (v5):** For each claim, assess whether the underlying source itself is reliable. Company press releases are not the same quality as audited financial filings. Grade the source, not just the claim.

- GENERATED DOCUMENT = None → ABORT. Nothing to verify.
- RAW SOURCE MATERIAL = None → Cannot verify against source. Can only check internal consistency and flag claims that REQUIRE sources but don't cite any. Output clearly marked: "INTERNAL CONSISTENCY CHECK ONLY — no source verification possible."
- DOCUMENT TYPE = Not stated → default to highest materiality (Board presentation). Better to over-check than under-check.

## PHASE 1: CLAIM EXTRACTION

Extract every specific factual claim from the generated document. A "claim" is any statement of fact that could be verified — numbers, dates, named entities, trends, percentages, causal relationships, rankings, comparisons.

**EXTRACTION RULES:**
- Opinions and interpretations are NOT claims (skip them)
- Predictions marked as predictions are NOT claims (skip them)
- Any prediction presented as fact IS a claim (flag it)
- Compound sentences may contain multiple claims (split them)

---

## PHASE 2: VERIFICATION TABLE

For EACH claim:

| # | CLAIM | SOURCE EVIDENCE (exact quote or reference) | SOURCE QUALITY (v5) | VERDICT | CONFIDENCE | MATERIALITY |
|---|---|---|---|---|---|---|

**Verdicts:**
- **VERIFIED** — Exact match or clear paraphrase of source content
- **INFERRED** — Reasonable inference from source, but not explicitly stated. Flag the inference logic.
- **AMBIGUOUS** — Source could support this interpretation, but also others. Flag the ambiguity.
- **HALLUCINATED** — No source evidence. The AI made this up.
- **CIRCULAR** — The "evidence" is the document's own output or another AI-generated document
- **OUTDATED (v5)** — Source evidence exists but is older than 12 months. For fast-changing data (share price, headcount, market position), flag as potentially stale.
- **EXTRAPOLATED (v5)** — AI took a real data point and projected/extended it beyond what the source supports. Common with trend claims.

**Source Quality (v5 — Bellingcat Grading):**
- **A: Audited Financial** — Annual Report, 10-K, audited accounts. Highest reliability.
- **B: Official Filing** — Companies House, SEC, regulatory filing. High reliability.
- **C: Company Statement** — Press release, website, investor presentation. Company-controlled. Medium reliability.
- **D: Third Party** — Analyst report, trade press, Glassdoor. Independent but may be dated.
- **E: AI-Generated** — Output from another GAIN prompt or AI tool. LOWEST reliability. Must be verified against A-D sources.

**Materiality:**
- **CRITICAL** — If wrong, damages credibility in Board/client setting. Career risk.
- **SIGNIFICANT** — If wrong, weakens the argument but doesn't destroy it.
- **MINOR** — If wrong, unlikely to be noticed or challenged.

## THE OPERATOR LOOP

Ask: *"If it hallucinates once, scrutinise the entire document. Do a manual spot-check of the single most critical financial metric yourself — never trust AI on the number that will be on the Board slide."*

**Conditional routing:**

IF verdict is DO NOT USE:
→ "This document has material hallucinations. Do NOT send it. Regenerate the source prompt (G-01/G-02/G-04/etc.) with better source data, then re-run G-14."

IF verdict is NEEDS REVISION:
→ "Fixable errors found. Apply the remediation from Phase 4, then re-run G-14 on the revised document to confirm clean."

IF CIRCULAR sourcing detected:
→ "The document is citing AI outputs as evidence for AI conclusions. This is the most dangerous hallucination pattern — it looks convincing but has no foundation. Trace every key claim back to a human-generated source."

IF OUTDATED claims found at CRITICAL materiality:
→ "Key data is stale. Before using in [materiality context], verify these specific data points are still current: [list]. Financial data older than one reporting period should be refreshed."

**NEXT MOVES:**
→ Fix and re-verify: Apply remediation → re-run G-14
→ Regenerate source: Re-run the original prompt (G-01/G-02/etc.) with better inputs
→ Competitor audit: Paste competitor marketing as Generated Document + their 10-K as Source
→ Final delivery: If SAFE TO USE → proceed to G-05/G-06/G-11/delivery
